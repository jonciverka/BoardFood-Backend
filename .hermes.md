# Proyecto: boardFood

## Este repositorio
- **Pieza:** Backend (API)
- **Repo:** `BoardFood-Backend`
- **Stack:** Node.js + Express, MySQL, Firebase Admin, cron

## Qué es
Sistema de menús digitales / comida para restaurantes (BoardFood).

## Repositorios que componen el proyecto

| Pieza | Repo | Stack |
|---|---|---|
| App principal | `BoardFood` | Flutter + mysql2 (con base local `baseDB`) |
| Backend (API) | `BoardFood-Backend` | Node.js + Express, MySQL, Firebase Admin, cron |
| Landing | `Boardfood-landing` | HTML/CSS/JS estático |

## Stack principal (backend)
- Node.js + Express
- MySQL (mysql / mysql2 / express-myconnection)
- Firebase Admin (fcm-push), cron, morgan, axios, ejs

## Cómo ejecutar el backend
1. `npm install`
2. `npm run dev` (o `npm start`)
3. Requiere: MySQL corriendo + credenciales Firebase

## Notas
- Workspace: `BoardFood.code-workspace` agrupa las 3 piezas (app + backend + landing)
- **Duplicado:** existe otro archivo workspace en `BoardFood-Backend/src/api/BoardFood.code-workspace` que apunta a las mismas carpetas — usar el de la raíz
